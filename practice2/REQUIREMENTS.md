# Практика 2 – Реализация MVP

## Требования к выполнению:
- Реализовать микросервисы и взаимодействие между ними (синхронно через HTTP/gRPC или асинхронно через очередь).
- Хранение данных (PostgreSQL).
- Обязательное наличие автотестов (интеграционных или юнит-тестов для каждого сервиса).
- Использование docker-compose для локального запуска всех сервисов.
- Вынесение БД на отдельный микросервис в отдельном контейнере (позже это превратится в отдельный под в K8s).
- Реализация асинхронных задач (через очередь сообщений).
- Написание полноценной спецификации OpenAPI (Swagger).
- Покрытие тестами > 80% кода.
- Разработать фронтенд.
- Интеграция с внешним API (Telegram, почта, AI).
- Graceful shutdown и healthchecks во всех сервисах.

## Требования к стуктуре кода
- Папка `practice2/services/` с кодом каждого микросервиса (отдельная подпапка).
- Файл `practice2/tests/` с автотестами.
- Файл `docker-compose.yml` для локального запуска.
