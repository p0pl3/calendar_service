# Сервис "Календарь событий" с напоминаниями

## Требования:
- 3 диаграммы в нотации С4 (контекст, контейнер, компонент)
- Реализация микросервисной архитектуры как минимум из трех сервисов с их взаимодействием.
- Каждый микросервис должен быть упакован в Docker-образ.
- Наличие хотя бы одного внешнего хранилища (база данных, кэш, очередь сообщений) или интеграции с внешним сервисом (почта, Telegram, AI API и т.п.).
- Автотесты (минимум 3 сценария) для проверки основного функционала.
- Развёртывание в облачном кластере (Managed Kubernetes) с использованием манифестов (Deployment, Service, Ingress).
- Автоматизация деплоя через GitOps (ArgoCD).
- Подключение системы мониторинга для сбора и визуализации метрик.
- Распределённая трассировка (Jaeger, Tempo) и централизованный сбор логов (Loki, ELK).
